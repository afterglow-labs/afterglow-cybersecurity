# iOS client status

The server contract and session migration were merged and deployed before the
iOS application was resumed. The native client now targets API version 1.

The app includes task, conversation, finding and evidence screens, model-profile
selection, secure session restore, retry recovery, themes, six-language native
labels, and an independent full-console session. See [README.md](README.md) for
installation, feature access, security behavior and reproducible build commands.

Validation and release artifacts are recorded in the release notes and
[verification record](verification.json). Simulator screenshots and detailed
Xcode results are retained as build/CI artifacts; generated products are ignored.
