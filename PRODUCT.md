# Afterglow Cybersecurity product

Afterglow Cybersecurity is a self-hosted research console for planning, executing, and reviewing authorized security tests in locally isolated environments. The Go backend stores tasks and evidence in PostgreSQL; the Next.js interface presents asset and exploration graphs, live worker controls, model and MCP settings, and finding review. An optional browser extension captures an operator's authenticated browsing into the same traffic evidence store. Shipped detection rules and host triage tools help defenders recognize activity from this code lineage.

The interface supports English, Korean, Simplified Chinese, Traditional Chinese, Japanese, and Spanish. Internal binary, database, environment-variable, and API identifiers retain ScopeWeaver/ARTEX names for compatibility. Public claims must distinguish the inherited ScopeWeaver verification record from checks performed on this merged checkout.
