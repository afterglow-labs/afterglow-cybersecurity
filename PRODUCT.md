# APTEX by Afterglow Labs product

APTEX by Afterglow Labs is a self-hosted research console for planning, executing, and reviewing authorized security tests in locally isolated environments. The Go backend stores tasks and evidence in PostgreSQL; the Next.js interface presents asset and exploration graphs, live worker controls, model and MCP settings, and finding review. An optional browser extension captures an operator's authenticated browsing into the same traffic evidence store. Shipped detection rules and host triage tools help defenders recognize activity from this code lineage.

The interface supports English, Korean, Simplified Chinese, Traditional Chinese, Japanese, and Spanish. Internal binary, database, environment-variable, and API identifiers retain ScopeWeaver/ARTEX names for compatibility. Public claims must distinguish the inherited ScopeWeaver verification record from checks performed on this merged checkout. See [README.md](README.md) and [docs/AFTERGLOW-MERGE.md](docs/AFTERGLOW-MERGE.md).

APTEX is an independent product with its own client, server, accounts, configuration, and data. Useful Odysseus features may be ported into this codebase with their dependencies, tests, and provenance. Those ports must run within APTEX's lifecycle and use APTEX's own settings and credentials.

The Obsidian, Phosphor, and Afterglow presets provide compact cybersecurity styling with cyan, green, and amber accents. Every preset supports light, dark, and system appearance. New sessions default to dark Obsidian, while saved theme and font preferences take precedence.
