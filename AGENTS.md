# Afterglow repository workflow

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing code. Keep the source and test-scope restrictions in [README.md](README.md), preserve upstream attribution, and update [docs/AFTERGLOW-MERGE.md](docs/AFTERGLOW-MERGE.md) when importing another fork's feature.

When the owner asks to push finished work, merge it into `main`, push to the remote, and apply it to the local APTEX deployment. PRs may be used, but complete their merge before reporting the work as pushed. Verify the running deployment matches the delivered revision. Respect explicit requests to keep a branch isolated or a PR unmerged.
